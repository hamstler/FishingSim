# FishingSim

Original RF4-style fishing simulator, Godot 4.3 .NET (C#). Polish README in README.md.

## Build / test
- Licence: GPL-3.0-or-later for the whole project (LICENSE; README section "Licencja" lists the third-party parts). Exports: `export_presets.cfg` (Windows, Linux) include `assets/fish/*` and exclude tools/tests/docs; the .glb models carry `importer="keep"` .import files (never a .gdignore in assets/fish: exports skip such folders).
- `dotnet build` (Godot.NET.Sdk 4.3.0; in offline sandboxes restore via the bundled GodotSharp/Tools/nupkgs source).
- Tests: `FISHSIM_NO_SAVE=1 godot --headless --path . res://tests/run_tests.tscn -- <suite>` (core, accounts, progress, world, game, tournaments, village, gear).
- Screenshots: `tests/screenshot.tscn` (use xvfb-run + `--rendering-driver vulkan` with lavapipe, ~30 s per shot; volumetric fog needs Forward+).

## Architecture
Pure logic in src/Core (injected IRng); data as .tres resources; saves via System.Text.Json.Nodes; shaders in shaders/.

## Art direction
- One look only: Nordic (Valheim-like). Native resolution in the root viewport, crisp procedural textures, volumetric fog with sun shafts, AO, bloom, teal-shadow/warm-light grade (GraphicsQuality.ApplyNordic), moonlit ambient at night (SkyController). Pixel art was removed.
- Textures (everything but the fish): 4096 px per 2 m tile (ground, bark, buildings; leaf atlas 4096 with 2048 cells, needles 2048, fern 1024x4096), painted on worker threads (GroundTextures records strokes and paints them in 32 parallel bands; designs are in 1024-px units scaled by K) and block compressed by the game itself (Graphics/BlockCompress: BC1 colour, BC3 colour+alpha, BC5 normal RG: Godot's compressors exist only in the editor), cached zstd-compressed in user://texcache/*.fstx (Graphics/TextureStore; bump the owner's CacheVersion/LeafVersion when a design changes; stale versions and old PNGs are deleted). Menu starts painting them in the background (GroundTextures/Textures/ProceduralTextures Prewarm*); headless runs skip them. Trilinear anisotropic filtering (BuildingFactory.Pixel). Window starts maximised, canvas_items stretch, 3D at native resolution. Fish skins: src/Graphics/FishSkin paints them per pixel on worker threads (512×256 for fish in the lake, 4096×2048 + normal map for hooked/held/atlas fish via FishModel.Create(..., detailed: true)); screenshot mode 20 = skin sheet, 19 = atlas. Decor: pier festoon lights (Scenery.BuildStringLights), golden fish signs, Graphics/Gulls.
- Photographed CC0 materials (the user wants everything free for commercial use: only CC0 sources): Poly Haven sets in assets/textures/<id>/ (diff.webp, nor.webp = OpenGL normal, disp.webp for grounds, info.json with the real size), fetched by `python3 -I tools/assets/polyhaven.py [--grey] [--disp] ids` (4K by default; the game reads them at TextureStore.MaxSize, so only Ultra loads the 4K level, Low 1K, Medium/High 2K; GroundTextures.PhotoSize 4096, bump PhotoVersion/PhotoTextures.Version when the sets change) (hosts api.polyhaven.com, dl.polyhaven.org; CREDITS.md rewritten), "keep" .import files (the game decodes and block-compresses them itself: Graphics/PhotoTextures, cached in texcache). Used when present, painted designs otherwise: BuildingFactory.Photo(id, tint) (walls triplanar at the set's metres, roofs by UV in metres), ground layers (GroundTextures.Photos, 2048), bark (TreeFactory.BarkMaterial(kind): pine_bark / bark_brown_02, painted birch), pier deck. Geometry has soft edges: Shapes.RoundedBox replaces BoxMesh in BuildingFactory.Box; log cabins are real logs (Shapes.Log, LogWalls); roofs are thick rounded slabs. CC0 props (Poly Haven, `--model`): assets/models/<id>.glb (+ .json) with WebP pictures, loaded by World/Props/PropAsset (GltfDocument for meshes, pictures decoded and compressed by the game, ORM channels), used by Barrel, Crates, Lamp/Lantern, Campfire (stone_fire_pit), Well bucket, Goods baskets, Woodpile stump; headless runs fall back to primitives. Villagers and the angler's arms: Quaternius's free Standard packs (CC0; the user rejected his low-poly "Ultimate Modular" people as not realistic enough): Universal Base Characters (heads, eyes, hair), Modular Character Outfits Fantasy (Peasant, Ranger), Universal Animation Library 1+2. `python3 -I tools/assets/quaternius.py [--src DIR]` fetches them from itch.io like the "No thanks, just take me to the downloads" link (hosts quaternius.itch.io, itch.io, itchio-mirror.cb031a832f44726753d6267436f3b414.r2.cloudflarestorage.com) and writes assets/characters/: <model>.glb (male/female peasant/ranger: outfit parts + the base body cut to the head and the upper chest under the collar (pulled 1 cm in) + eyes, brows, every hairstyle of that sex as its own mesh, all re-bound to the outfit skeleton (65 UE-style bones, bones along local +Y, T-pose with palms down), tangents computed, surfaces named skin/eye/hair1/hair2/outfit, no pictures), anims_male/anims_female.glb (23 animations retargeted per bone relative to the rest pose, only the pelvis keeps translation, scaled), textures/*.webp (decoded and BC-compressed by the game, cached, prewarmed from the menu), <model>.json (pictures per material incl. two outfit colourings, hair meshes). World/Props/CharacterAsset.Create(Appearance, idle) instantiates a PackedScene per model, sets materials (skin SSS, double-sided cloth and hair, ORM), shows one hairstyle/beard/hood, adds an AnimationPlayer with the shared library; HeadLook (SkeletonModifier3D) turns neck_01+Head to the camera. People.Dress picks model, appearance, idle (FoldArms, Talking, Farm_*) and gestures per Role; Npc.Rig plays them, nods ("Yes") at the angler, stops animating beyond 70 m. Fishing/FirstPersonBody shows only the peasant's "Arms" mesh with its eyes at the camera (leaning 15 cm forward) and World/Props/ArmIK (SkeletonModifier3D: two-bone IK to a wrist target with a pole, hand frame from fingers/palm directions, half the twist into the forearm, finger curl by Grip) holds the rod handle (GripHandle/GripPalm/GripFingers in rod-rig space) and the reel knob (the landed fish is not held: the user found it artificial); FISHSIM_IK_DEBUG=1 prints the solve. Headless runs keep the primitive figures and built hands. Screenshot modes 23 (studio lineup: arg 0 roles, 1 models in both colourings, 3 head close-up) and 24 (in front of villager ARG, FISHSIM_SHOT_DIST).
- Ground and nature materials (no toon lighting anywhere): World/Props/GroundTextures paints seven seamless 2 m layers (grass, forest floor, sand, path, lake bed, rock, snow; 1024 px, height in the albedo's alpha, normal map RG = tilt, B = cavity, A = roughness) into Texture2DArrays (albedo BC3), cached in user://texcache (bump its CacheVersion). LakeBed.GroundAt writes the weights into the terrain mesh's UV (sand, path) and UV2 (forest floor, bed); shaders/terrain.gdshader height-blends the layers (borders wander by noise), rock by slope/altitude (triplanar), snow by altitude, two rotated readings against tiling, the map's colours via layer_tint (each layer's mean becomes the map's colour, meadows slightly calmed). Boulders: TreeFactory.Boulder + shaders/rock.gdshader (the rock layer, triplanar, moss on tops). Trunks: TreeFactory.Trunk (root flare) + shaders/bark.gdshader with GroundTextures.Bark (furrowed, or birch). Leaves: ProceduralTextures.LeafCluster = 2x2 atlas (oak, birch, willow, hazel; LeafCards' atlas cell) or needle sprays, FernFrond for ferns; the crown depth rides in the vertex alpha. Flowers: TreeFactory.Wildflower + shaders/flower.gdshader. Two-sided grass/foliage/floating shaders undo the engine's back-face normal flip (`if (!FRONT_FACING) NORMAL = -NORMAL;`) or half the blades/leaves go black. Clouds: soft cumulus lit through three steps towards the sun (sky.gdshader). Headless runs skip painting the ground and bark.
- Performance: never set sky material params or move the sun every frame (re-bakes radiance); cloud drift is the global shader param `cloud_drift`. Per-frame values shared by many materials are global shader params (water_time, water_amp, foliage_wind, foliage_time; terrain caustics use water_time), never per-material sets each frame. Physics ticks are capped at 4 per frame (project.godot) and only real physics runs there (Player, Bobber forces, FishingRod's state/fight); visuals that follow the camera or must be smooth at any frame rate run in _Process (rod bend and line, fish schools with dt clamped to 0.05). Nodes with nothing to do disable processing (Building without spinners/lights, ForagePatch until picked); throttle what changes slowly (minimap 15 Hz, insect swarms 4 Hz, lamp flicker only within 70 m); no LINQ or array allocations in per-frame code (InteractionManager.Nearest, SoundEngine pushes fixed 256-frame chunks). View distance (GraphicsQuality.View, pause menu "Zasięg widzenia", saved with the quality): ViewRange ends the distant forest (far tree LODs fade out; 0 = horizon) and ViewFactor scales detailed trees, plants, grass, buildings/props (Scenery.Prop(root, range) -> VisibilityRangeEnd, OmniLight distance fade), villagers (drawn within 150 m x factor, animated within 70 m x factor) and sun shadows. Profile with FISHSIM_PERF=1 and screenshot mode 13 (prints the GPU's objects/draw calls/primitives; FISHSIM_VIEW=0..3 picks the view distance, FISHSIM_QUALITY=0..3 the quality, FISHSIM_SCALE=50..100 the 3D resolution). In game, F11 = UI/PerfOverlay (top left, 4 Hz, averages per frame: FPS, worst frame of the last second, CPU = the sum of the Perf scopes ("kod gry"; Godot's TimeProcess is the worst whole frame of the second incl. drawing, useless for scripts) + the viewport's measured CPU render time, physics = TimePhysicsProcess (worst step of the second), GPU = RenderingServer.ViewportGetMeasuredRenderTimeGpu (measuring only while shown; lavapipe reports nonsense), the card holds the frame back when GPU >= 0.8 x frame, objects/draw calls/primitives, 3D size, RAM/.NET/VRAM, busy thread-pool workers, and the slowest Perf scopes: Perf.Live sums them per window without allocating; scopes on main-thread callbacks only); FISHSIM_PERF_OVERLAY=1 shows it in screenshots. 3D resolution (GraphicsQuality.RenderScale, pause menu "Rozdzielczość 3D" 100/85/70/50, saved as "scale"): below 100 the root viewport's Scaling3DMode is FSR (UI stays native); the sandbox's lavapipe cannot measure real frame rates, ask the user for F11 numbers. Memory: TextureStore.MaxSize (Low 1024, Medium/High 2048, Ultra 4096) skips the top mip levels of cached textures as they are read (FishAsset resizes its pictures to it, FishSkin.DetailedSize follows); the sun's shadow atlas is 2048 on Low; Main.ReleaseLoadingGarbage collects (and compacts the LOH) once per map load; GrassField disposes the old MultiMesh at once and fills the new one through one reused buffer (VisibleInstanceCount). Dispose Godot resources you replace often (their native/GPU memory lingers until the GC finalizes the wrapper). Screenshot mode 32 = memory soak (prints RSS, GC heap, objects, nodes, resources, VRAM every 40 frames; FISHSIM_SOAK_FRAMES).
- Water (shaders/water.gdshader, Water.cs): no longer pixel art: swells matching Water.HeightAt + wind ripples (foam_noise derivatives) + rain rings; refraction and Beer-Lambert absorption from the depth buffer (hint_screen_texture/hint_depth_texture, the material composites itself: EMISSION = refracted*through*(1-F) + SSR hit, ALBEDO = scattered body colour, SPECULAR gives the sky reflection and sun glints); screen-space reflection steps by quality (ssr_steps: 0/12/20/32; reflections of the far shore are not showing yet); shore foam from the real depth. Fish are opaque, cast shadows, and are drawn only when FishPopulation.Sight (Fresnel glare vs. transmission through the water, depth, clarity, polarized glasses) > MinSight.
- UI look: src/UI/UiArt paints the interface (carved oak nine-patch panels with brass studs, planked buttons incl. gilded "gold" ones via UITheme.Primary, parchment, spotlight, gilded bars, coin/lock/owned/star badges); UITheme.Make uses it for every screen. The shop has a category rail (TabContainer kept for tests, TabsVisible=false), sub-category chips (Shop.Subcategories), search/sort/"Dostępne", tier ribbons by RequiredLevel, hover/appear/pop tweens, coin burst + OneShot.Coins on purchase (FishingRod.Cue). Icons are painted on a 4x canvas (smooth shading, soft outline, drop shadow) and saved at 128 px.
- UI pictures: src/Graphics/Icons (items, fish), src/Graphics/Postcard (one composition per map). Screenshot modes 16 (icon sheet), 17 (postcards) and 18 (top-down map shapes) run headless.
- Villages: LocationData.VillageStyle (timber/farm/fishing/mountain -> BuildingFactory.Style: walls, roofs, shutters, fences, villager roles) and Streets (door paths go to the nearest street); kinds Cabin, RedHouse, StoneHouse, Smokehouse, Tent, MarketTent, Stall, Well, Woodpile, DryingRack, Cart, Villager (BuildingFactory.Village.cs); every functional building gets its keeper (AddKeeper). LakeBed.VillageGround eases the village to the square's height (MapLayout.PlazaHeight) so pads do not make mounds.
- Collision: buildings, fences, landmarks (incl. the dike's crown and sloped sides), stalls and villagers have their own StaticBody3D colliders; World/Solids (Scenery.Solids, one StaticBody3D on layer 1, shapes shared by size, cleared on rebuild) holds the rest: tree trunks inside the map (PlayDistance < 2: cylinder TrunkRadius(kind) x scale x 1.1, 3 m), near-shore boulders (cylinder from the unit boulder's scale), campfires (0.7 m) and their seat logs, laundry/net-rack poles, chopping block and trunk, tool rack, rowboats, the notice board, the local anglers' logs. Landmarks reserve their ground (_reserved: a row of 6 m circles along the dike, 8 m for the others) so trees, plants and anglers keep off. Player: water and the map edge (LakeBed.IsWalkable) are walls it slides along (keeps the X or Z part of the step that stays walkable). The game suite probes with an angler-sized capsule.
- Sitting villagers: Npc.Seat (SeatModelHeight 0.455, SeatModelBack 0.334 model units x ModelScale, measured from Sitting_Idle_Loop with screenshot FISHSIM_SIT_PROBE=1) puts the hips over the log's axis and SeatLogRadius makes the log's top 1.5 cm above the seat (CampProps.SeatLog(even: true) keeps it as thick end to end); the hearth sitters and the local anglers use it, the anglers only on level ground (Scenery.Level: within 0.3 m over 2.5 m, the first such spot 1.5-7 m up the bank). Logs get unique names (Godot renames duplicates).
- Maps are unique via LocationData Squareness/Lobes/Islands (LakeBed.InsideMetres) and Landmarks (World/Props/Landmarks.cs). No primitive cone trees: a landmark that wants trees lists their feet in Building.TreeSpots (local) and Scenery plants real forest trees there (_landmarkTrees, in ScatterTrees: birch/oak, scale 1.15-1.45); the fish-pond dike is built of photo materials (leafy_grass bank, rocky_trail track).
- Relief and map edge: LakeBed.NaturalHeight adds HillsAt (domes in 46 m cells, at most 0.45 of their radius high, faded off the beach and around the village via Unflattened) and RimAt (mountains rising from the forest belt to LocationData.RimHeight with ridges; SnowLine/RockLine per map feed terrain.gdshader). The playable map is LakeBed.XMin..ZMax (also the minimap area); its edge is PlayDistance (rounded rectangle, wobbling) and IsWalkable stops the angler there, inside the dense rim forest (Scenery.ScatterTrees: 3.4 m jittered grid in the belt, sparser up the slopes to the tree line). The terrain mesh is a variable grid (GridLines: 2.5 m over the map + DetailMargin, widening to 14 m out to Outer) with collision only over the map. Trees are drawn per 64 m cell twice (Scenery.AddTrees): full near TreeNearRange, TreeFactory.GetFar versions (fewer, larger cards, 6-sided trunks) beyond.
- Foliage (Scenery: ScatterTrees records tree spots for the understorey of hazel + ferns; ScatterGroundCover, ScatterReeds, ScatterShoreline = rushes + yellow irises, ScatterWaterPlants = lily/pondweed patches by LocationData.LilyDensity, kept off the pier's water): small plants go through AddMultiMeshChunked (one MultiMeshInstance3D per 36-48 m cell with a visibility range scaled by GraphicsQuality.FoliageRange), no shadows for grass/reeds. Floating leaves use shaders/floating.gdshader riding the water's waves via the global shader params water_time/water_amp (set in Water.PushParameters) and float ~0.45 amplitudes up (the 2 m water mesh strays from the exact waves). Godot front faces are clockwise.
- No GPUParticles: rain is a MultiMesh + shaders/rain.gdshader (GPU particles with motion vectors crashed Godot 4.3 when two viewports drew them).
- Rod: src/Core/Physics/RodBendModel drives RodRig.SetJointAngles (RodData.Action). RodRig is a whole spinning rod (butt cap, cork grips, reel seat with hoods and nut at SeatCentre, fore grip, BlankStart 0.25, slim blank with whippings, guides under it from the stripper to the tip-top) with a classic fixed-spool reel under the seat (foot, thin stem StemAt, body, rotor + wire bail + line roller, spool with line and drag knob, crank on the LEFT: SetCrank/KnobAt). Hands (FirstPersonBody): BarGrip picks the roll round a bar that continues the arm's line from ArmIK.Shoulder (no bent wrists; the rod's handle slants 28 deg across the palm, thumb on top); KnuckleGap slides the hand so the reel's stem lies between the middle and ring fingers (Splay spreads them); the left hand pinches the crank knob in its fingertips. ArmIK closes each finger only until it touches its Obstacles (capsules: RodRig.SeatObstacles/CrankObstacles, HandTarget.Bar for tools), least overlap first. RigBasePosition keeps the knob within the left arm's reach (check with FISHSIM_IK_DEBUG=1: "reach d/max" must stay below max; its GRIP lines give each finger's clearance and the palm centre's distance from the handle in mm). BarGrip puts the wrist PalmDepth (0.012 m, half the hand's thickness) above the bar's surface so the palm lies on it; ArmIK.Arm.ThumbOn (world point) lays the thumb's tip on top of the handle 7.5 cm ahead of the hand; the left pinch closes to 0.97 round the knob. FISHSIM_CLOSEUP 4 = down the rod from the front at the grip, 5 = from above. FISHSIM_CLOSEUP=0..3 adds a camera beside the reel in any screenshot mode; FISHSIM_SHOT_SIZE=640x360 makes quick checks ~1.5 min.
- Quality presets in src/Graphics/GraphicsQuality (pause menu button): High (default) = SSAO + volumetric fog + TAA; SSIL, SSR, MSAA and 4 shadow splits only on Ultra; SDFGI off.
- Fish models: src/Fishing/FishBody (per-species build table, iris colours, mouth size) + FishModel (lofted with a rounded nose cap, cached per species at unit length, scaled). Close-up (detailed) fish use shaders/fish_body + fish_fin (one swimming wave from fish_bend.gdshaderinc, instance uniforms wiggle_amount/swim_phase), painted fins (Graphics/FinPainter: rays, membrane, markings), iris discs (EyePainter) under a cornea; head details (mouth, nostrils, gill cover, eye socket) are painted into FishSkin. Screenshot mode 22 = studio close-up (arg = species index, also writes *_head.png). Screenshot mode 21 = side views of 20 species per page (arg = page). Light skins are pre-painted in parallel when a lake is stocked.
- Fish references: the user rejected photo-textured fish ("too photographic"); fish stay painted and game-like, but species with assets/fish/<id>.json (FishReference) are lofted to the side-view profile and painted in the back/flank/belly colours measured from a freely licensed Wikimedia Commons photo (tools/fish_photos: fetch.py search/previews/more via commons thumb.php, cutout.py with --isnet [ISNet ONNX model, tool-only], measure.py, finalize.py; photos are not shipped, CREDITS.md lists them). FishModel.Growth/Proportions: heavier fish are deeper and thicker, young ones slimmer with bigger eyes; the landed fish is shown on UI/CatchPanel: full-screen dim + carved card, a SubViewport studio (own world, transparent over a spotlight, lights only) where FishingRod.HeldFishModel (made hidden under the camera, adopted by the panel, freed by the rod once decided) turns slowly about its vertical axis after spinning in, chips (weight, length = FishModel.Length, value, XP, record), warnings, E/R buttons; the stage height follows the screen (fits 720p). FISHSIM_SHOT_WEIGHT sets the weight and FISHSIM_SHOT_WAIT the seconds to let it turn in screenshot mode 2.
- Species models (all 66): tools/fish_model. measure_atlas.py measures a side-view illustration (AtlasRyb.online, measurements only: body outline without fins via steep-edge fin spans + asymmetric smoothing, then a second pass that bridges the back/belly under each found fin with margins for its short first and overhanging last rays, so no hump at the fin (Long dorsals of carp/crucian end at the last steep drop before the stalk); fins and eye are given in the snout-stalk axis frame like the outline; each fin's base and edge, the eye by a pupil-in-iris matched filter at several sizes with the table's position as a prior (EYE_HINT/EYE_SMALL for pictures that defeat it), colour bands, fin colours; CROPS picks one fish on pictures with two) -> compose_species.py joins it with the game's tables (FISHSIM_DUMP_FISH=<file> in the gear suite dumps FishBody/skin style/iris/mouth) and the perch's head anatomy (species/okon.json is the hand-tuned template, mapped by snout/eye/gill-cover landmarks) into species/<id>.json (fin bases snapped onto the outline); relatives without a picture borrow one (REFERENCE/ADJUST tables), curled or missing fish (sum, wegorz, sumiki, glowacze, babka) are built from FishBody envelopes. fishgen.py smooths the outline (monotone cubic, snout made convex over its first 0.04, a rounded nose cap as long as the snout's front is broad), sculpts the mouth in proportion to the gape (ML: lips, crease running through the snout's tip, rings kept from folding) and paints textures at 4096x2048 for every species (normal map at full size, fins 1024x512; unwrapped skin with overlapping scales (thin dark edge + light middle, contrast by scale size, growth rings, radii and edge pigment close up; cheek scales only for perches) or smooth skin, patterns: bars/saddles/light_spots/red_spots/dark_spots/rainbow/vermiculated/marbled/stripe(s)/spot_rows/band/scutes/mirror, head anatomy, normal map; fins; iris; barbels) and writes the lake outline (--reference). fish_blender.py (blender -b) builds the glb with WebP pictures (EXT_texture_webp, quality 85, encoded once from fishgen's lossless PNGs: smaller and truer than JPEG then WebP; quad body 190x128, Solidify fins with ray tubes, Mirror paired fins, barbel tubes, eyes in a socket 0.45 eye radii deep so the dome rises out of its floor beyond the iris (the skin never cuts the iris), turned to face as the head's surface does, under clear corneas, the iris metallic to its rim with a dark edge, darker above; stickleback spines are free needles to each measured tip). tools/fish_model/build_all.sh rebuilds everything (Blender 4.0 + python3-numpy from apt; the environment's setup script installs them). FishAsset loads assets/fish/models/<id>.glb at run time (GltfDocument for meshes; the pictures are decoded by FishAsset itself with mipmaps and S3TC-compressed (BC1/BC3, BC5 for the normal map; FISHSIM_RAW_FISH_TEXTURES=1 keeps them plain), on a worker thread via FishAsset.Prefetch when a fish nibbles; at most 6 species stay cached); FishModel.BuildAsset uses it for close-up fish, with shaders/fish_eye + fish_cornea so the eyes sway with the head. FISHSIM_SHOT_SIZE=WxH sets the screenshot size.

## Camp life
- Core/Camp/CampLife.cs (pure, IRng): GroundKind (LakeBed.GroundKindAt: water, rock above RockLine, path, beach sand, the damp bank below 1.3 m = Mud, forest, meadow), Digging.Dig (worms by ground richness, night crawlers "rosowka" at night/in rain, grubs "pedrak" in forest, a spot dug within 1.2 m gives nothing), Sweeping (mayflies "jetka" over the water 16-22 h in calm weather by swarm density, grasshoppers "insect" on warm meadows, chafers "chrabaszcz" near trees at dusk), Cooking (Roast: 1 fish >= 0.12 kg on any fire; Soup: 2+ fish >= 0.6 kg, needs the pot or a village hearth; picks the cheapest fish, undersized first), MealBuff (XP and bite-wait bonus for game hours: Profile.Meal/MealHoursLeft, saved, PassTime ends it; AddCatch and FishingRod.NewBiteTimer apply it). Accessories lopata (Shovel), siatka_na_owady (InsectNet), garnek (CookingPot); baits jetka, pedrak.
- Fishing/HandTools (child of the player, body frame): Q cycles Rod/Shovel/Net (only owned; the rod only when idle; FishingRod.Holstered blocks it and hides the rig), LMB Use(): keyframed tool poses (Catmull-Rom, DigKeys/SweepKeys), Player.WorkPitch/WorkBlend/WorkOffset bend the head and body over the work, Player.Busy stops walking; events: Dig thud + clods (World/DigMarks), clod with wriggling worms on the blade, toss, hole + heap; Sweep swish, haul at the ring. - World/InsectSwarms: up to 14 shore spots (nearest the pier first, 24 m apart), MultiMesh + shaders/mayfly.gdshader (instance uniform fade), DensityAt/Deplete. ## Game rules worth knowing
- Tackle (data/tackle/*, lists in TackleLoadout and GearCatalog): RodKind/LineKind/BaitKind; TackleSlot.Leader ("brak" always owned) limits LineStrength and replaces line visibility; LineData.Stretch adds to rod shock absorption, braid +10% hook-set; BaitData.AffinityAs/AffinityScale resolve via species' family keys (spinner/spoon/wobbler/softbait/fly, written into data/fish) when a species has no entry of its own (FishSpecies.AffinityFor, BaitFamilies); lures (Reusable) are not used per bite, are lost with the hook, and the bite timer runs only while reeling; FishSpecies.BiteOff = per-second chance to bite through a non-wire leader; accessories Waders (LakeBed.WadeLimit), HookHone, ReelGrease.
- Methods (src/Core/Methods/FishingMethods.cs, pure, tested in the core suite; FishingRod.CastMethod fixed at the cast): Method.For(rod kind, bait kind): a lure = Spinning on any rod (LureRodMatch: spinning rod 1.25, else 0.85), bait on Bottom/Carp rods = Bottom, else Float; HookWindow 0.9 / 1.8 / 1.2 s. Spinning: LureMotion per LureFamily (bait.AffinityAs: spinner/spoon/wobbler/softbait/fly; LureSpec sink rate, run depth slow/fast, ideal speed range, snag rate, still pace, twitch dart): depth by retrieve (FishingRod: normal = reel speed x0.3, Shift x0.6), BitePace (quality, falling jig, lift bonus after a fall, twitch flash) drives the bite clock x2 x LureRodMatch; RMB in Waiting = JerkLure (twitch, or jerk a snag: 35 % free, 8 % break), LMB on a snag pulls (12 %/s free, breaks after 4 s -> BreakLine(Hook)); SelfHookChance(aggression, reeling) starts the fight at the knock; the nibble is one knock and RMB at it strikes. The rod holds the Bobber (frozen) where the lure runs (_rigPos, depth) or the feeder lies. Bottom: the feeder takes one bait as groundbait when >= 2 (Cast), sinks 1.6 m/s, feeds GroundbaitSpots (5 m radius, strength cap 3, FadeHours 1.5 via World.Hour deltas, cleared on map change; PaceFor up to 2.75x; fish attraction scaled too); nibble = quiver plucks (Twitch 0.45), bite = _bitePull bends the tip; LMB drags the rig slowly. Bobber.SetTerminal shows the float (distance-scaled), the lure (built per family: spinner blade spin, spoon roll, wobbler rock, jig tail wag by LureSpeed, facing Heading) or the feeder; TerminalVisible = false in the fight for lure/feeder. RodRig.SetQuiverTip (bottom/carp rods: last two sections bright orange). Rod rest (Z, Fishing/RodRest: hazel fork, or metal with a bell when AccessoryKind.RodPod is owned; Ring swings it): PutOnRest raycasts the ground 0.8 m ahead, reparents the RodRig to the rest (25 deg up towards the line's end, back rest under the butt), FirstPersonBody.RigOnRest hides the arms and leaves the rig; Origin() follows the rest; no reeling/lifting; TryHook at Nibble/Bite needs NearRest (3.5 m) and picks it up; ResetToIdle picks it up. - Line physics: Core/Physics/LineRope (40 points, Verlet + one-sided length constraints, pinned ends; air: gravity, drag, wind; surface film holds floating lines (mono, braid), fluoro sinks; bottom from LakeBed.HeightAt read once per step; taut when Length <= straight distance). - Feeding levels and bite styles (Core/Methods/FeedingHabits, tables by SpeciesName; default level 1 = bottom, style Dive): BiteContext.BaitLayer (1 bottom .. 0 surface, null = not judged) x LayerFit (distance in the water column in metres, floor 0.12) multiplies BiteModel.Weight. FishingRod.BaitLayerAt: float = FloatDepth / water depth (FloatDepth 0.2-6 m, keys [ ] (Shift 0.5) or Ctrl+wheel, only when Idle; not saved), bottom = 1, spinning = lure depth / bottom while in the water. OverDepth (setting > water + 0.15): Bobber.Tilt 1 (float lies flat), hook chance x0.75. Float bites by style (FloatNibble/FloatBite): Pluck quick weak dips, Lift negative Bobber.ExtraForce + Tilt (rises and lies flat), Run DriveVelocity away then under, Dive as before; SetState clears tilt/drive/lift outside Nibble/Bite. Wind: Bobber.Drift = WindVelocity x 0.02 while waiting (the tight line holds it).
- Spooking (Core/Methods/Disturbance, pure): Level decays with HalfLife 35 s, Pace = 1 - 0.75 x level multiplies all three bite clocks; Splash(method, lure weight, depth) on landing (also FishPopulation.Scare -> FishSwimModel.Scare sets Fear around the splash), Steps(speed, distance to bait, wading, dt) from the camera's motion each physics tick (FishingRod.TickDisturbance), +0.3 at StartFight; cleared on map change; HUD "ryby spłoszone" when Spooked (> 0.45). Disturbance.Masking(weather, wind) (rain x0.6, wind x(1 - 0.25 w)) scales Steps and Splash (FishingRod.NoiseMasking).
- Pressure and temperature (Core/Methods/Conditions, pure): WorldState.Barometer steps in Advance (pressure eases to 1022/1012/1001 hPa by weather, smoothed Trend hPa/h; Pace 1.2 slowly falling, 1 steady, 0.82/0.7 rising, x0.92 long low) and multiplies the bite clocks with Disturbance.Pace (FishingRod.ConditionPace). LocationData.WaterTemperature (gory 11.5, jezioro 17, zatoka 19.5, staw 21.5) -> WaterTemperature.At(lake, hour, weather) (+-1.5 by day, cooler in rain) -> WaterTemperature.AtDepth(surface, bait depth = depth x BaitLayer) (mixed top 1.5 m, then -0.9 deg/m, min 6; at each bite WindowFactor(that temperature) 0.7..1.15 scales the hook window: FishingRod.HookWindowNow) -> BiteContext.WaterTemp x WaterTemperature.Fit(species: cold 11+-5, warm 22+-6, else 17+-7; tables by SpeciesName). The dial's plaque has a fourth line (pressure, trend word, water temperature; tinted by the pace).
- Thrown hooks: FightModel.HookHold (init; FishingRod sets chance x (1 - 0.4 x lateness in the window), 0.55 for self-hooks, 1 with DevInstantBite); SlackSeconds grows while the line is slack (slack > 0.3 m or tension < 6 % of peak pull); after 0.5 s the fish shakes it out at (0.25 + 0.7 surging + 0.3 aggression) x (1.05 - hold)^1.5 per second -> FightOutcome.HookThrown -> FishingRod.LoseFish (no tackle lost). Runs sometimes start with a 0.7-1.4 s dash at the angler (chance 0.05 + 0.15 aggression; Charging). HUD "LUZ! zwijaj" (FightSlack).
- Bait wear (Core/Methods/BaitWear, pure): LifeMinutes per bait id (real time in the water), freshness steps in FishingRod's physics tick (WearBait; AgeBait for tests); Appeal 0.35..1 multiplies the float and bottom bite clocks (BaitPace, 0 with a bare hook); bread/ciasto/kasza fall off when spent; a missed or lost bite (AfterMiss) keeps the bait only 35 % of the time; reset at every cast; lures exempt; HUD word via BaitWear.Word.
- Line wear (Core/Methods/LineWear, pure; Profile.LineWear id -> 0..0.6, saved as "line_wear"): FishingRod adds FromLoad(tension, line strength) every fight tick, PerFish at landing, PerSnagJerk / PerSnagPullSecond on snags; ApplyTackle (also at ResetToIdle) uses LineWear.Strength for LineStrength; Profile.Buy of an owned worn line respools it (wear reset, price charged); Destroy clears it; Shop shows the wear on the card and a "Nawiń nową" button for the worn line in use; HUD tackle line names it.
- Line twist (Core/Methods/LineTwist, pure; Profile.LineTwist id -> turns, saved as "line_twist"): the spinning retrieve adds PerMetre(lure family, swivel) per metre pulled (spinner 1, spoon 0.45, softbait 0.12, wobbler 0.04; x0.12 with AccessoryKind.Swivel = 13, data/tackle/accessories/kretlik.tres); Cast rolls TangleChance(twist, line kind) (from Loops 40 turns, braid x0.35, fluoro x1.3): a bird's nest (LastCastTangled) cuts the cast speed to 0.3, halves the twist (AfterTangle) and adds 0.03 wear; landing a fish takes FightRelief(fight seconds) off; Profile.NeedsRespool (worn or twisted) lets the shop respool it (clears wear and twist); HUD tackle line adds the word.
- Hook wear (Core/Methods/HookWear, pure; Profile.HookDull id -> 0..0.6, saved as "hook_dull"): +PerFish(weight) at landing, +PerSnag when a lure snags; SetFactor(dull) multiplies the strike chance; K = FishingRod.SharpenHook (needs AccessoryKind.HookHone, Idle) -> Profile.Sharpen; Profile.Buy of an owned blunt hook replaces it (Shop "Nowy haczyk"); Destroy clears it; HUD tackle line adds the word.
- Casting (Core/Methods/Casting, pure): Scatter(power, rng) -> degrees off the aim (soft bell, 1.5 + 4.5 x power) and a speed factor; WindCatch(method, lure weight) -> Bobber.WindCatch with Bobber.AirWind = FishingRod.WindVelocity pulls the flying end tackle's horizontal velocity towards the wind (x0.35).
- Structure (Core/Methods/Structure, pure): Scenery.WeedBeds (every lily/weed patch from ScatterWaterPlants, cleared on rebuild; Main sets FishingRod.WeedBeds) -> CoverAt (1 in a bed, 0 four metres out); FishingRod.StructureAt(x, z) adds Edge from the depth gradient (EdgeFrom: 0.45 m/m = 1); BiteContext.Cover/Edge x Structure.Fit (cover lovers 0.7-1.3, edge hunters 0.8-1.25); MakeBiteContext(depth, at) and BiteChances(depth, at) for the map's hover readout (which also names plants/drop-offs). ## Repository size
- The .glb models take ~350 MB for all 66 as committed (about 270 MB once rebuilt with the current WebP-85 encoding); main's history already holds every model version up to PR #5 (~1.2 GB of blobs, 742 MB on GitHub). Every full rebuild adds its whole size to the history: rebuild only the species that changed (`tools/fish_model/build_all.sh <ids>`), and before a branch with several full rebuilds is merged, keep only the final models in its history (rewrite the branch-only commits so that assets/fish/models appears in its last commit, then push with --force-with-lease).

## Known issues
- The first start bakes the 4K photo sets: TextureStore.Get disposes its intermediate Images and Collect()s after every picture >= 2048 (native pixels otherwise wait for finalisation: the menu peaked at 3.9 GB); dispose Images you only bake. Unhandled .NET exceptions are written to user://logs/crash.txt (CrashLog, installed by the menu); Godot's own log is user://logs/godot.log. CrashLog keeps user://running.flag while the game runs; found at start (the last run crashed), it deletes user://shader_cache and user://vulkan (a crash mid-write left "Malformed smolv" caches that crashed every start). A user's RTX 3080 crashed (signal 11) after glslang failed on a valid built-in shader and RIDs came back null: memory exhaustion, hence 4K only on Ultra.
- Intermittent exit 134 when running several suites in one process.
